# FPL Challenge picker

Picks a squad for the current FPL Challenge gameweek, explains each pick, and
records it so the model's accuracy can be measured week on week.

Standard library only. No installs.

## Run it

```
python scripts/fpl_data.py       # refresh data (first run ~2 min, then cached)
python scripts/fpl_solve.py      # print the recommended squad
python scripts/fpl_track.py record
```

After a gameweek finishes:

```
python scripts/fpl_track.py score
python scripts/fpl_track.py report
```

`SKILL.md` is the full operating guide, including the weekly twist file format
and the model's known limitations. Read it before changing anything in
`scripts/`.

## Timing

Challenge does not lock the whole team at once. Players lock individually when
their match kicks off, so this is worth running more than once a gameweek — at
gameweek open, and again before each batch of kickoffs. Confirmed lineups are
published 20–40 minutes before kickoff, which is the window where a re-solve
has the best information.

## What is not in the repo

`data/cache/` and `data/players.json` are generated by `fpl_data.py` and
gitignored. A fresh clone rebuilds them on the first run.

`data/starters.json` **is** committed. It holds the expected starting eleven for
each club and is partly hand-checked, so it is the main lever for improving
picks and the thing most worth keeping under version control.
